## Problem

### How to accept inputs

Ok - so let us begin your journey.

For solving programming problems, your code needs to accept system provided inputs.
The $input()$ function in  **Python**  allows user input.

- The default parameter accepted in the $input()$ function is a string
- All values entered using input() are treated as strings, even if they look like numbers.
### Task

Write a code to accept a string as input and output the same.
Some portion of the code is already written for you.
You need to replace the _ (underscores) with correct code in the editor.
Once done, click  **Submit**.
